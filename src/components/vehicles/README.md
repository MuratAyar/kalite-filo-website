# Vehicle components

This directory contains the shared vehicle-list components. Vehicle-detail
components remain deferred until their records and presentation contract are
approved.

As of 2026-08-14, the project owner has approved the workbook `Portföy_32`
`Önerilen Liste Net` values for display on the three Home cards and all 32
catalogue cards. Render them only as monthly TRY net list prices with an explicit
`KDV hariç` qualification. This approval does not establish `Nihai Yayın Net`,
VAT-inclusive amounts, duration/kilometre terms, validity, availability, or
service scope. Do not infer those fields or turn the list price into a complete
`VehicleOffer`.
